4. GitHub Workspace 컴포넌트

GitHubWorkspace

Feature

repository 등록, webhook feed, PR diff review, markdown 기반 issue/PR/comment/commit 작성 UI를 담당합니다. 현재 app route에 직접 mount된 구조는 아니며 기능 컴포넌트로 존재합니다.

  • Repository sidebar: Card, Input, Checkbox, Label
  • Home feed: webhook event card list
  • PR review: file navigation, split/unified diff, line selection
  • New action panel: Select, Input, MarkdownRichEditor

MarkdownRichEditor

Client

Lexical 기반 Markdown editor입니다. textarea preview 방식 대신 입력 영역 안에서 Markdown shortcut과 rich text 렌더링을 제공합니다.

  • LexicalComposer
  • RichTextPlugin, HistoryPlugin, ListPlugin, LinkPlugin
  • MarkdownShortcutPlugin
  • MarkdownSyncPlugin

7. 변경 제안 포인트

Route별 feature folder

현재 study, github, theme, layout, ui로 분리되어 있습니다. 파티 상세 기능이 커지면 components/party 또는 features/party로 이동해도 됩니다.

GitHubWorkspace mount 위치

GitHub PR review UI는 기능 컴포넌트로 구현되어 있으나 현재 홈/파티 route에 직접 연결된 화면은 아닙니다. 파티 상세의 Pull requests 탭 아래로 연결하는 것이 자연스럽습니다.

Header active state

현재 공통 상단바는 정적 링크입니다. 현재 route를 반영한 active state가 필요하면 client navigation component로 분리할 수 있습니다.

UI primitive 유지

폼, 버튼, 탭, 카드, 아바타는 shadcn primitive를 유지하고 feature component는 domain action과 state orchestration만 담당하는 방향이 좋습니다.

이 문서를 수정한 뒤 "변경요청 복사"를 누르면 현재 문서 내용을 기반으로 Codex에게 반영 요청할 수 있는 텍스트가 클립보드에 저장됩니다.
